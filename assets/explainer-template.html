01 · Intuition

A small push, repeated

Put a microphone near a speaker. The microphone picks up a small sound. The speaker plays it louder. The microphone picks it up again. Each pass can make the sound smaller, keep it the same, or make it larger. The loop gain decides which one happens.

The same nudge can fade, hold, or grow. The difference is the gain.
01

Input

Something enters the loop: a sound, a deposit, a temperature change, or a request.

02

Gain

The loop multiplies the input. A gain below 1 shrinks it. A gain above 1 enlarges it.

03

State

The result becomes the next input. The loop remembers the last value.

04 · Boundaries

Where this explanation breaks

A linear model is a starting point, not a universal law. Three limits matter.

LIMIT 01

Gain is not constant

Real amplifiers saturate. A loop that grows at first can flatten when it reaches a physical limit.

LIMIT 02

Delay changes the story

If the feedback arrives late, a loop can oscillate even when a delay-free model says it should settle.

LIMIT 03

Noise is everywhere

The model assumes a clean signal. Real loops also amplify noise, and some of that noise is unpredictable.

05 · Check

Can you use it?

Answer before you open each panel. If an answer feels shaky, go back to the mechanism step that supports it.

1. Recall: what decides whether a loop settles, holds, or grows?

The loop gain. Below 1, a disturbance shrinks each pass. Near 1, it persists. Above 1, it grows until a limit intervenes.

2. Transfer: what happens if you add a long delay to the feedback path?

The response can oscillate. The correction arrives after the state has moved, so the loop can overshoot and reverse direction.

3. Boundary: why is “gain above 1 means runaway” incomplete?

Because real systems saturate, change gain over time, and contain noise. A linear constant-gain model is a local approximation, not a guarantee.
